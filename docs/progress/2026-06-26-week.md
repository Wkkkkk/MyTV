## Shipped features

### Playlist item integrity (fix)

- **`next_sort_order()`** in `src/model/playlist_item.rs`: computes `MAX(sort_order) + 1` for the channel, used by both create paths when the caller does not pin a `sort_order`. Fixes the root cause of all items landing at 0 when added via the JSON API.
- **`find_duplicate()`** in `src/model/playlist_item.rs`: channel-scoped lookup matching on `url` OR `title` — catches re-encoded copies of the same video, not just exact-URL duplicates.
- **API create path** (`src/routes/api/playlist.rs`): calls `find_duplicate` first; on a hit, returns the existing item with HTTP 200 (silent idempotent skip). On a miss, calls `next_sort_order` when the caller omits `sort_order`.
- **Admin form create path** (`src/routes/admin/playlist.rs`): same dedup guard, mirrors the API. The form already auto-incremented `sort_order` in the UI but the DB path had no server-side guard.
- **Tests** (`tests/api.rs`): 2 model unit tests (`next_sort_order`, `find_duplicate`) + 3 API integration tests (first add, duplicate URL, duplicate title).
